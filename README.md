# 💳 PaymentMonitor - نظام مراقبة المدفوعات وإدارة الكاشير

نظام متكامل ومحلي (Offline-First) لإدارة ومراقبة المعاملات المالية والمحافظ الإلكترونية. يعتمد النظام على قراءة رسائل الـ SMS من الهواتف المحمولة لالتقاط إشعارات الدفع، وإرسالها إلى سيرفر مركزي، ليتم عرضها وإدارتها عبر لوحة تحكم ويب وتطبيق كاشير لسطح المكتب.

## 🏗️ معمارية النظام (System Architecture)

يتكون النظام من 4 تطبيقات مستقلة تعمل معاً بسلاسة:

1. **السيرفر المركزي (Server):** مبني بلغة Python (FastAPI) ويعمل كملف `.exe` مستقل. يحتوي على قاعدة بيانات SQLite ولوحة تحكم ويب مدمجة.
2. **تطبيق الكاشير (Cashier):** تطبيق سطح مكتب (C# WPF) لاستقبال وتأكيد المعاملات.
3. **تطبيق الموبايل (Mobile):** تطبيق أندرويد (C# MAUI) يعمل في الخلفية لقراءة رسائل SMS الخاصة بالمحافظ (جوالي، جيب، كاش، وغيرها) وإرسالها للسيرفر.
4. **أيقونة التحكم (Tray App):** تطبيق خفيف (C# WPF) للتحكم بالسيرفر (تشغيل/إيقاف/تثبيت كخدمة) من بجوار الساعة.

---

## ✨ المميزات الرئيسية (Key Features)

- **عمل محلي بالكامل:** لا يحتاج إلى إنترنت، يعمل عبر الشبكة المحلية (LAN).
- **قراءة تلقائية للرسائل:** تحليل ذكي لرسائل المحافظ الإلكترونية (AmFlos, Jeeb, Mobile Money).
- **نشر سهل (Portable):** السيرفر والكاشير لا يحتاجان لتثبيت Python أو .NET (يتم بناؤها كـ Self-Contained).
- **لوحة تحكم ويب:** إحصائيات فورية، تقارير، تصدير Excel، وإدارة الكاشيرين والمحافظ.
- **يعمل كخدمة (Windows Service):** يمكن للسيرفر أن يبدأ تلقائياً مع إقلاع نظام الويندوز.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Backend:** Python 3.14, FastAPI, Uvicorn, SQLite.
- **Frontend (Web):** HTML/JS/CSS (مدمج داخل السيرفر).
- **Desktop App:** C# 12, .NET 10 (WPF), WebSockets.
- **Mobile App:** C# 12, .NET MAUI (Android).
- **Packaging:** PyInstaller (للسيرفر)، dotnet publish (للتطبيقات).

## 🚀 دليل التثبيت والنشر (Deployment Guide)

النظام مصمم ليكون "محمولاً" (Portable)، مما يعني أنه يمكنك نسخه إلى أي منشأة جديدة وتشغيله في دقائق دون تثبيت برامج إضافية.

### 1. تجهيز السيرفر (الكمبيوتر الرئيسي)
1. انسخ مجلد `PaymentMonitor.Server` إلى الكمبيوتر.
2. افتح المنفذ `5000` في جدار الحماية (Firewall) عبر موجه الأوامر كمسؤول:
   ```cmd
   netsh advfirewall firewall add rule name="PaymentMonitor Server" dir=in action=allow protocol=TCP localport=5000
